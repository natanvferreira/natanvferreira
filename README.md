## 🚀 Projetos

### 🌀 Arcly
Tracker de animes e mangás no estilo AniList. Agrupa automaticamente as obras por franquia (todas as temporadas de um anime juntas, na ordem certa), com listas customizadas públicas ou privadas, notas e reviews, perfil público com estatísticas e favoritos.

`Laravel` `Vue 3` `Inertia` `PostgreSQL` `Redis` `Docker (Sail)` `Tailwind CSS`

> 🔒 Código privado — em breve no ar!

### ⬇️ BaixaAí
Baixe vários vídeos do YouTube de uma vez, em vídeo ou MP3, com uma interface simples. É só baixar o .exe e usar, sem instalar nada

`Python`

> 📂 [Ver repositório](https://github.com/natanvferreira/baixai)
